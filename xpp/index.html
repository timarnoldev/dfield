Equilibrium continuation

Starts at the equilibrium nearest to the initial values (Newton) at the current parameter value. Thick = stable, thin = unstable. Tap a point in the diagram for details.

Periodic orbits (simulation sweep)

Integrates at each parameter value from the end state of the previous one and plots max/min (green dots) of stable oscillations. Choose “period” as Y axis to see periods.
